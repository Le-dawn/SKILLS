# 检查与诊断：不生成也能用

本技能不只用于生成。大量问题可以在不占 GPU 的情况下定位：读剧本、读分镜、读提示词、抽帧看片、对记录。检查的产出是**证据 + 结论 + 该修哪一层**，不是新视频。

## 0. 通用做法

1. 明确对象：剧本、分镜、提示词、已有片段、成片、还是记录与版本。
2. 取证据：原文行号、抽帧、ASR、回执、选片清单、版本表。
3. 按层归因：脚本／分镜 → 提示词 → 输入绑定 → 生成 → 剪辑 → 验收。
4. 分开写“已确认”和“未确认”；没看、没听的项写未完成，不写成通过。
5. 只检查时明确声明“不提交生成”；发现需要重做时给新版本，不覆盖旧产物。

## 1. 剧本检查（含提案与大纲）

- **常识与时间线（阻断项）**：人物年龄与时代背景、技术介质是否匹配；人物核心行动是否符合其职业常识与物理空间常识（如隔音、距离、行业流程）；有无为了制造冲突而强行降智或违背基本生活经验的设定。
- **台词逻辑与反伪金句（阻断项）**：检查关键台词（尤其是情感金句、潜台词）的主谓宾与动机是否自洽——“谁说的、对谁说、目的是什么、逻辑通不通”；剔除主客体颠倒、时空死锁（如让已故者在生前预设死后别人向自己提问）等伪文艺台词。
- **体量与戏剧容量**：故事的事件密度、冲突层级是否撑得起目标集数与总时长；有无把单幕短片硬拆成多集注水，或结局情绪兑现与追剧时长严重失衡。
- **动作因果**：每个承接动词有没有前置——交付→接收、借出→归还、离开→回来、发现→反应。缺前置就是断因果。
- **桥**：每次进出、换场有没有视听提示；没有就会“下一秒人已瞬移到位”。
- **时长**：按自然语速和动作依赖估算 floor，扣除合理重叠，串行动作才相加；看它落在容量区间的什么位置，有没有为凑目标增删节拍。
- **台词长度**：按对白、动作重叠与收口余量估算总耗时，逐段核对试读或估时依据；超过已确认的工作流上限须拆段。
- **AI 高危交互排查**：核心叙事是否过度依赖手机屏幕小字特写、复杂烹饪与连续进食、高频精细手部拆装；若是，有无可观察的视听替代方案。
- **产出**：问题表（行号／段落、问题、类型、建议、是否阻断）。

## 2. 分镜检查

- **机位预算**：每场几个机位；同一段对话是否被切成碎片，或反过来变成毫无视觉变化的超长站桩镜头。
- **单次生成时长**：按实际工作流限制检查（当前随附执行器请求 4–15 秒）；一段可多镜，一镜可跨段，不以固定舒适区代替负载判断。
- **桥清单**：换场、进出、折返是否有足够视听依据，不强制各加独立镜头。
- **交接**：是否写成可观察状态（接触 → 承托 → 松手 → 归属）。
- **视线与位置**：是否用场景内的物理锚点（如桌案内外侧、门口、窗边、主家具方位），有没有误用“画面左/右”。
- **时长账**：分镜合计 vs 剧本 floor；差额是否有解释。
- **产出**：分镜体检表 + 合并或拆分建议（哪几镜该并／拆、调整后多少秒）。

多段项目另按[片段计划](segment-planning.md)核对：节拍覆盖、全片／局部时间、采用区间与重叠扣除、边界动态状态、未生成依赖及跨段声音方案。

## 3. 提示词检查（生成前）

- **独立性与映射**：已加载 batter 版及适用参考；每段从局部 `[Shot 1]` 开始，后续切点在段内递增；不用“同上”替代身份与状态；局部引用和说话人 ID 映射到本次真实输入及全局身份。
- **六问**：画内有谁、物理位置、各动作阶段看谁、转向依据、动作顺序、道具状态、有无自相矛盾句。
- **引用绑定**：`<Picture N>`／`<Audio N>`／`<Video N>` 是否连续、是否点名身份、`anchor_image_index` 是否指对。
- **反模式**：看画外导致模型切广角、台词变画面文字、程度词失效、道具走位、无身份身体、屏幕左右。
- **产出**：逐镜 P1／P2 清单，每条给“具体句子 + 改法”，不做泛泛评价。

## 4. 片段检查（生成后）

- **首帧**：核对实际 Guide 绑定，并检查身份、构图和动作起点是否满足设计；二采不保证像素等于关键帧。
- **切点对比**：同镜续接查运动与状态连续；换机位结合空间基准查物理关系、遮挡和动作阶段，不要求背景像素位置相同。
- **关系**：视线配对、场景功能分区（如主客位、内外侧）、交接是否真正完成、出入方向。
- **伪影**：衣服/墙面/道具上有没有生成文字或贴纸；有没有无身份的人。
- **道具状态**：与本集状态账本比对。
- **声音**：原声听审为主；ASR 只用来定位漏词、改词、错说话人。
- **产出**：采用／弃用／重做，附证据帧与帧号。

## 5. 成片检查

- 解码完整、帧数与时间线一致、画幅与帧率正确。
- 响度与峰值；字幕与剧本逐字一致、时间不压末帧。
- 切点连播前后各约 1 秒。
- 与选片清单、版本表一致，没有混入未采用的版本。
- **产出**：交付体检报告，含未完成项。

## 6. 记录与版本审计

- 选片清单里的采用版本，是否与实际输出、回执一致。
- 每个片段的版本 ID、输出目录、回执是否齐全。
- 版本表有没有孤儿版本、重复采用、被替代但仍被引用。
- **产出**：不一致清单（可自动生成，如“片段版本表”）。

## 7. 症状 → 该查哪一层

| 症状 | 最可能层 | 先查什么 | 修复动作 |
| --- | --- | --- | --- |
| 对错人说话 | 提示词／分镜 | 该镜视线句与对手位置 | 重写该镜各阶段的视线目标与转向依据 |
| 同场像换屋 | 分镜／关键帧来源／空间基准 | 切点差分、两镜固定物逐项对照、关键帧来自哪张底 | 先检查四图布局与实际绑定，再结合四图与最新账本逐镜派生关键帧；例外见一致性资产 2.6.4 |
| 交接没完成 | 分镜／提示词 | 交接句是否可观察 | 重写为接触→合手→松手 |
| 台词变画面文字 | 提示词／机位 | 抽帧看衣服与背景 | 强禁文字或改机位 |
| 时长异常 | 剧本／分镜 | floor 与三账 | 按因果与交付约束调整结构，缺桥才补，不压词 |
| 执行成功但内容不对 | 验收 | 抽帧与听审 | 记录为生成偏离，不写成通过 |
| 接缝有跳变 | 剪辑／选片 | 入出帧与相邻版本 | 重选区间或重做该镜 |

## 8. 边界

- 不能只看 ASR 或字幕判断口播正确。
- 不能只凭执行器 `completed` 判断内容通过。
- 不能把“放大静帧才看得见”当成可读。
- 没看过的、没听过的，写“未确认”，不写“通过”。
- 检查结论不等于用户验收。

## 9. 跨机位空间一致性（换轴必查）

同一场里每出现一次换轴，在生成前和剪辑前各做一次：

1. 两张关键帧（或两镜首帧）里，门窗／主家具／台面／地面／隔断等固定陈设逐项列形状、材质、相对位置。
2. 对照“是否同一间屋”：排除正常视野、投影及遮挡变化后，确认固定物无依据缺失、物理位置改变或材质重建才判不通过。
3. 对照“人物锚点”：区分人物离场与切近景造成的出画；物理位置须有依据，不强制画外对手持续出声或露身体。
4. 对照“道具状态”：关键道具在谁手里、在哪、开合朝向；两镜必须能连上。
5. 细部漂移（抽屉分格、台面嵌板）单独记录为残余问题，不冒充已解决。

## 10. 场景四图与实际绑定

- 四图齐全：正面、反向平视回望、45°俯视斜角全景、90°垂直正俯视完整平面；同一布局，前后非镜像，方向可对应。
- 生成记录核对依赖：反向图实际引用正面图；45°图实际引用前两张；90°图实际引用前三张。检查前序版本和哈希，不把文字描述当成图片输入。不得并行生成本组后续视角或先出俯视图。
- 上游换版后，下游按依赖链重做并复核；步骤检查通过才继续，检查不等于新增用户审批点。
- 逐图及交叉检查门窗、固定家具、尺度、通道；区别正常遮挡与无依据改位。
- 每条涉及场景的任务声明 scene_ids，images 实际包含完整四图；新项目 require_scene_references=true，既有项目新任务也不能省略契约。
- 提示词逐张说明实际 Picture 编号与空间作用，联合遵循；API 四条参考连线齐全。图片总量不超过 9，不能缩减四图凑额度。
- 续接首帧另行绑定，四图不替代动作起点；动态账本不覆盖固定布局错误。
- 缺图或矛盾保持 draft。例外须有明确用户依据与原因；旧任务恢复不批量迁移。
- 四图绑定完整不等于模型遵从；生成后仍看片核对空间和当前状态。
