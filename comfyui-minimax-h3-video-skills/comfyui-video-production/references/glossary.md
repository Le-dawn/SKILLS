# 术语表与口径

这份表统一制作、提示词、验收、版本记录里的说法。同一件事只用一个词；出现新词先补进这里，再在别处使用。

## 1. 镜头、片段、版本

| 术语 | 定义 | 不是什么 |
| --- | --- | --- |
| **镜头（逻辑镜头）** | 一次连续的摄影机视图，例如 S03、V07；可经多段生成拼成连续观感。旧项目的“逻辑镜头”若含切镜，保留旧 ID 并映射到实际镜头，不改写历史 | 不是一次生成任务，也不是一个文件 |
| **生成片段（clip）** | 模型一次生成输出的视频文件，例如 `08_输出/V01_v02/…/00_214.mp4` | 一次请求对应一份提示词；一段可含多个镜头，一个连续镜头也可跨多段 |
| **任务版本** | 同一个生成片段计划的一次生成尝试，例如 `V01_v04`、`S08_v03`。版本号只增不减，旧版本不覆盖 | 不是镜号；镜号不变，版本会变 |
| **采用版本** | 最终进入剪辑的那一条片段 | 不是“最新版本”，也不是“执行成功的版本” |
| **镜号** | 分镜给镜头的编号（S01、V07）。改设计可换镜号，改素材只换版本 | 不是任务 ID |

镜头与生成片段是多对多映射。镜号标识连续视图，片段 ID 标识一次请求的计划，任务版本标识一次尝试，片段文件是其输出。项目编号不等于提示词中的局部 `[Shot N]`。

### 场次与场次编号（C01、C02…）

| 术语 | 定义 | 要点 |
| --- | --- | --- |
| **场次（scene）** | 一段连续时空里的戏，按“地点＋时间＋事件”划分。一场可以包含多个镜头，也可以只有一个 | 场次是叙事单位，不是生成单位 |
| **场次编号 C01、C02…** | 分镜表里给场次编的号，C 取“场”（chapter/scene），按叙事顺序递增；后面通常跟场名和累计时间，例如 `C01｜门槛上的打工人｜0–24.5 秒` | 这是可选本地编号，不是行业标准；由当前项目定义 |

关系：

- **场次 → 镜头；镜头 ↔ 生成片段 → 任务版本**：场次包含若干镜号；片段计划映射一个或多个镜头，每个片段可有多次生成尝试。不得因一段内有多个镜头而强行拆成多个请求。
- 场次编号不随重做变化；改设计才动场次或镜号，改素材只动版本。
- 时长分配、状态账本、验收记录都按场次分节，便于对照“这一场用了多久、哪些镜、哪些状态”。
- 场次边界与镜号映射以当前项目采用的分镜版本为准。

## 2. 什么是“同一镜头”

判定标准是三条同时成立：

1. **没有切**：摄影机机位、镜头、角度不变（固定机位就是完全不动；运动镜头则运动连续）；
2. **时间连续**：中间没有时间跳跃、没有省略；
3. **动作连续**：人物的动作阶段接得上，没有“跳过一个动作”。

三条都成立，才是**同一镜头**。任意一条不成立，就是**切镜**，哪怕还在同一间屋、同一段对话。

### 关系判定表

| 关系 | 判定 | 例子 | 素材怎么做 | 剪辑怎么做 |
| --- | --- | --- | --- | --- |
| **同镜续接** | 三条都成立，但一次生成放不下（超过当前工作流上限或表演负载过高） | S04→S05：完整分句之间拆段，并另行安排连续声音 | 用上游**实际采用版本的剪辑末帧**作首帧锚 | 按实际重复决定是否跳过首帧，连播切点前后各 1 秒 |
| **同场切镜** | 同一场景、同一段时间，但机位/景别/角度变了 | V02→V03：从柜台后切到她坐凳 | 用状态账本里的实拍帧派生关键帧；切点须交代站位和动作依据，不强制目的位置提前入画 | 检查切点差分、视线配对、人物在场关系、动作阶段 |
| **换场** | 时间或空间跳跃 | 店内 → 巷子 | 重新建立空间；必要时加桥 | 检查观众是否知道“到了什么时候、什么地方” |

**关键**：同场切镜**不用**尾帧做首帧锚。把上一镜的帧直接当新机位首帧，会把人物锁死在前一镜的构图里。

## 3. 锚定与素材

| 术语 | 定义 | 要点 |
| --- | --- | --- |
| **关键帧** | 用作某镜第一帧的静态图 | 必须逐张验收：身份、位置、视线、道具、画内人数 |
| **首帧锚定** | 把关键帧设为任务的第 1 张图并指定 `anchor_image_index=1` | 首帧锚定 ≠ 尾帧续接；任何关键帧都能做首帧锚 |
| **尾帧续接** | 只用上游**实际采用片段在实际剪辑切点**的那一帧做下游首帧 | 只用于同镜续接；换轴、反打、换场都不用 |
| **静态锚** | 剧本定稿后提前生成的识别特征：人物三视图、标志性场景特征、关键道具 | 只回答“是不是同一个东西”，不回答“这一镜在哪、什么状态” |
| **状态账本** | 本集逐镜记录动态状态的表：位置、朝向、开合、数量、光位、服装、新增物件 | 每条状态带来源（片段版本 + 帧号） |
| **抽帧** | 从采用片段里取代表帧、道具特写帧、衔接末帧 | 抽帧是账本和下一镜素材的来源 |
| **派生** | 用账本里的实拍帧生成下一镜的关键帧 | 同机位可直接裁切/推近；换轴用作空间参考再构图 |

### 3.5 场景四图

| 术语 | 定义 | 边界 |
| --- | --- | --- |
| 场景四图 | 同一布局的 front、back、overhead_45、top_90 四张独立参考图 | 默认每条涉及该场景的生成任务四图全部绑定，不任选一张 |
| 正面／反向平视回望 | 先建立正面图，再实际参考它生成同一空间的反向平视回望图，记录拍摄位置 | 反向图不是前图水平翻转 |
| 45°俯视斜角全景 | 向下约 45°观察整体空间、高度与布局，记录水平朝向 | 全景表示覆盖范围，不是 equirect |
| 90°垂直正俯视完整平面 | 正上方完整观察平面布局，明确图上方对应方向 | 不是让交付镜头变俯视 |
| 场景基准／动态账本 | 前者约束固定布局，后者记录人物和可移动物件当前状态 | 首帧和账本均不替代四图；固定布局漂移不能靠更新账本接受 |

生成依赖为 front → back（参考 front）→ overhead_45（参考 front＋back）→ top_90（参考 front＋back＋overhead_45）；不是四图并行生成。

方向、任务字段和例外见[一致性资产 2.6](consistency-assets.md)。

## 4. 节拍与时长

| 术语 | 定义 |
| --- | --- |
| **因果节拍** | 没有它观众就看不懂“为什么”的节拍（递钱、找零、道谢、发现） |
| **桥节拍** | 交代时间、空间、进出、折返的节拍（来客进门、起身、买豆浆回来） |
| **气氛节拍** | 只提供情绪或节奏的节拍，可以删，不许为凑时长新增 |
| **floor** | 本集最短可行时间线估计：考虑对白与动作的因果依赖和合理重叠，详见时长与流畅度 |
| **三账** | 剧本预计、分镜预计、实际成片三个时长分别记录，不必相等 |
| **合并长镜** | 同段对话与连续机位，时长和表演负载合适时可合为一条，减少接缝；不保证生成过程无漂移 |

## 5. 验收与版本

| 术语 | 定义 |
| --- | --- |
| **采用** | 通过验收、进入剪辑的版本 |
| **弃用** | 验收不通过、保留留档的版本（写明原因） |
| **切点差分** | 切点两侧的状态对比；同机位可叠看定位异常，换机位按物理关系核对，不要求像素相同 |
| **视线配对** | 切点前人物看的方向，等于切点后对手所在的位置 |
| **动作阶段** | 一个动作进行到哪一步（手伸出/接触/握住/松开）。切镜两侧必须能解释 |
| **未确认** | 没看到、没听到、没验证的项，必须写未确认，不能写通过 |

## 6. 最容易混的四组

1. **同一场 ≠ 同一镜**：都在修理铺里，有意剪切到另一机位是切镜；连续运镜改变机位不算切镜。场次（C01）是叙事分组，镜头是拍摄单位。
2. **同机位 ≠ 同一镜**：机位没动但时间跳了、动作跳了，也是切镜。
3. **尾帧续接 ≠ 首帧锚定**：前者专指用上游实际末帧做同镜续接；后者泛指用任意关键帧定第一帧。
4. **切镜 ≠ 换场**：同场切镜仍在同一时空；换场是时间或空间跳了。
