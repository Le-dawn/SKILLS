# 项目与素材约定

本文件承接可迁移的项目管理规则；新工作区没有 AGENTS.md 也可使用。制作顺序、四图依赖链、动态账本与阶段门槛以 SKILL.md 及其专项参考为准；执行字段与恢复规则以[执行适配](comfyui-h3.md)为准，不另设一套流程。

## 一部作品一个目录

每部独立作品放在工作区的 `videos/YYYY-MM-DD_名称/`；系列公共设定与单集输入分开。设定、素材、提示词、工作流、任务、回执与成片都归入作品目录，工作区根目录仅留通用说明、工具和共享资源。

```text
videos/YYYY-MM-DD_名称/
  project.json
  00_开始阅读.md
  制作设定.md
  分镜草案.md                 # 可按实际片长命名，不强制180秒
  素材清单.json
  01_角色/
  02_场景/
  03_道具/
  04_声音/
  05_提示词/镜头/
  05_提示词/美术生成提示词.md
  06_工作流/来源/
  07_任务/jobs.json
  07_任务/runs/
  07_任务/制作记录/
  07_任务/剪辑选片.json
  08_输出/
  09_交付/
  99_归档/
```

按阶段建立实际需要的文件，不用空占位冒充已完成产物。入口说明记录当前阶段、采用版本、未解决反馈和下一步。进入已有作品先读入口、project.json、jobs.json，再核对选片与回执。

共享角色或工作流用于作品时复制并锁定本项目版本；不覆盖原始三视图、不删除原始工作流。API 图放 `06_工作流/`，源画布放 `06_工作流/来源/`，不可将前端画布直接提交。

## 命名、版本与状态

- 镜头依次用 S01、S02，技术测试用 T00 等独立编号；修订用 v01、v02。
- 已提交任务的素材、提示词、参数或工作流有变化时建立新任务 ID；保留旧输入、旧回执与源片，不覆盖换片。
- jobs.json 是提交顺序与就绪状态的唯一来源；draft 不提交，enabled=false 不参加默认批次，显式 --jobs 只能选取已 ready 的任务。字段细节见执行适配。
- 素材和配置引用相对作品目录，移动文件后核对文档、配置和任务引用；不把当前电脑的绝对路径写入项目配置。
- 原始生成结果进入 `08_输出/`；人工内容验收通过后才进入 `09_交付/`，旧版归档时保留可追溯引用，不移动破坏已提交依赖。

## 片段计划的归档

多段项目在既有分镜文档增加“生成片段计划”表，较大项目可独立为 `生成片段计划.md` 并在入口登记。按[片段规划](segment-planning.md)记录镜号映射、双时间轴、出入状态和引用依赖；规划信息不作为新字段随意塞入 `jobs.json`。沿用现有任务 schema 与执行器状态。

提示词按片段 ID 与版本保存到现有 `05_提示词/镜头/`，目录名不意味着一份只能写一个镜头。全局角色／声线 ID 映射到每份提示词的局部标签，四图也按本次实际输入顺序编号；保留已提交快照。

## 静态参考与生成记录

使用当前环境可用的内置图像生成能力；场景四图可按授权改用 ComfyUI 生图，所需额外工具见执行适配。内置生图不提交 ComfyUI；ComfyUI 生图占 GPU，服从实际授权范围。缺少能力时说明阻塞，不用文字充当图像。

美术提示词统一追加到 `05_提示词/美术生成提示词.md`，沿用 `Use case:` 前缀（identity-preserve / illustration-story / precise-object-edit / compositing），不另建平行记录。保存完整提示词、实际输入参考路径及哈希、生成版本与验收结果。场景四图的逐步累积参考要求见[一致性资产](consistency-assets.md)。

图片按“主体_视角.png”命名并归入角色／场景／道具目录，重做使用 _v02 等新文件名；`素材清单.json` 记录 width、height、bytes、sha256。每张打开检查真实尺寸、身份、构图、朝向和布局，检查通过才写入任务引用；模型声称的尺寸或身份保持不算证据。

不将凭据、临时认证副本或临时工作目录作为技能或作品资产分发；若生成工具需要临时认证文件，用后清理。特定宿主的 CLI、认证绕行和机器路径不作为本技能依赖。

## 记录与交付

- 日志、提交回执、有效工作流与参数快照保存在作品目录；state.json 与 runs 是恢复依据，不手工删除或改成成功。
- 用 `07_任务/剪辑选片.json`（或明确登记的版本清单）记录逻辑镜头采用的版本和剪辑区间；后期按清单取片，不凭“最新文件”推断。
- 制作反馈与逐接缝验收写入已有 `07_任务/制作记录/`，记录时间码、相邻版本、异常与修复结果；不为常规制作反馈、路径迁移或普通修复创建架构决策 Note。
- 提示词只写当镜可见道具，未到揭晓时不在共用提示词里提前给出隐藏物完整外观。
- 科普图、精确字幕和音量在后期统一处理，保留可复现命令或配置。静态参考、声音规范、实际音频、候选片与通过验收的成片分别说明。
- 通用规则与工具在技能内维护，作品事实留在作品目录，不在各片复制相互冲突的执行脚本。修改工具做必要离线／模拟测试，真实 GPU 试跑另按授权范围执行。
