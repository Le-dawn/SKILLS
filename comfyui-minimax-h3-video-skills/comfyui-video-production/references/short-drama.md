# 短剧与连续剧路径

用于单集或多集叙事，包括真人、动画和非人角色。单集先保证故事自足；仅当任务包含多集时，才建立系列人物变化、跨集道具状态与悬念回收，不预设集数或每集长度。

## 0．创意探索与剧本选择

用户只说“我想做一部短剧”、没有选定故事时，从这里开始：**口味探索 → 多方向提案 → 偏好收敛 → 大纲与试写 → 完整剧本**。目的是让用户逐步找到喜欢的故事与表达方式。已有故事、剧本或明确偏好时沿用，从尚未完成的环节继续；用户要求直接写或授权代选时，说明采用的方向并推进，不把下面每一步变成强制审批。

### 先了解口味

第一轮只补问最影响创作的 2–3 项，已有答案不重复问：想获得什么感受（好笑、温暖、紧张、情感拉扯等）；喜欢的作品、人物关系或想放进去的生活经历；不想出现的内容。参考作品要提炼用户喜欢的具体特质，不照搬人物与剧情。题材、真人或动画、单集或多集、受众与时长约束，结合上下文逐步补齐，不一次抛出整张制作问卷。

**交互边界**：需要补问时，提出问题后立即结束本轮回复，等待用户回答后再给提案；**严禁在同一轮回复中既写“先和你确认几件事”又自行假定答案直接输出提案**。用户没有想法、明确要求先看选择，或上下文已具备口味线索时，省去确认话术，直接给差异化提案。完成标准是已有可用的口味线索，或明确进入探索性提案；不要求用户先确定所有制作参数。

### 提供可比较的故事卡

首轮通常给 3–5 个简短提案；已有明确范围时可减少。各提案在人物关系、冲突机制、气质或结局方向上有实质区别，不只换职业和背景，也不只列题材标签。每张故事卡包含：

| 项目 | 写什么 |
| --- | --- |
| 暂定片名与类型 | 便于用户辨认和比较 |
| 一句话故事 | 谁想做什么，遇到什么阻碍（须与目标集数体量匹配） |
| 主角与关系 | 观众关心谁，人物之间有什么矛盾或牵连 |
| 核心看点 | 这个故事特别在哪里，主要带来什么观看感受 |
| 关键发展与结局方向 | 展示故事如何推进和收束；多集须说明阶段性推进引擎；向创作者说明关键揭晓，不靠藏底诱导选择 |
| 气质样例 | 一小段代表性情境或对白，让用户感受语言、节奏与情绪 |

**提案与故事卡的四条铁律（生成提案前必检）**：

1. **体量与戏剧容量匹配**：单集／短篇（1–3 集）可用单一悬念或单次揭秘支撑；多集连续剧（如 6–12 集）必须具备可持续推进的戏剧引擎（阶段性矛盾升级、认知反转或单元事件勾连主线）。**严禁把只够拍 5 分钟微电影的单次揭秘故事（如“教用手机→发现绝症诊断书”）硬切分成十几个集数注水**。若用户预设的集数远大于某类故事的自然容量，在提案说明中主动建议更匹配的集数或补足中段冲突。
2. **结局情绪兑现**：结局收束须与观众投入的总时长匹配。长线多集叙事在终局必须给出明确的关系落点或情感兑现，不滥用“擦肩而过未相认、一切毫无改变”的纯留白式反高潮结局。
3. **常识自洽与反“伪金句”**：
   - **年代与行业常识**：角色年龄推算的成长年代须与核心道具、技术介质匹配（如 30 岁以上角色的童年不可能有智能手机微信语音）；角色的行动不能违背其职业或生活基本常识（如快递从业者不会干等一件“已揽收未发出”四年的包裹而不去查始发网点；隔音差到能正常聊天就无需靠敲墙打暗号）。
   - **严禁伪深刻对白**：气质样例中的台词必须经得起“谁对谁做、为了什么、结果给谁用”的正常人类逻辑还原。**严禁为了追求文艺克制感，写出主客体颠倒（如“想念女儿却录下自己喊女儿吃饭的声音放给自己听”）、死人留活口（如“已故长辈当年故意写错菜谱好让晚辈在她死后回来问她”）等看似感人实则不通的伪金句**。
4. **AI 制作复杂度客观评估**：
   - **空间账**：固定场景数量决定“场景四图”的前期成本（起步项目宜控制在 2–4 个核心场景），但不把“场景极少、纯靠室内站桩说话”误判为最容易制作。
   - **表演与视觉账**：长时间缺乏动作与走位、纯靠面部微表情或隔墙独白撑戏的方案，极易放大生成视频的面部僵硬与视觉疲劳；提案须具备可见的动作抓手与空间调度潜力。
   - **高危交互预警**：凡将“频繁查看手机屏幕文字／UI”“复杂烹饪颠勺与连续进食”“高频精细拆封包装”作为核心叙事手段的提案，必须在制作补充中明确标记为高返工风险，或直接改为视觉更易实现的替代设计。

完成标准是用户能够比较具体故事及表达气质，而不只是从类型名称猜测内容。

### 根据反馈收敛

邀请用户选整案或局部元素，例如“喜欢 A 的关系、B 的氛围，但不要误会推动剧情，希望结局温暖”。整理喜欢、不喜欢、尚不确定三类偏好，再按需要给 2–3 个更贴近口味的修订方向；方向已清楚则直接展开，不为走流程反复出选项。

融合元素时重新组织人物目标、冲突与因果，不机械拼接。全部不喜欢时，先定位题材、人物、冲突、气质或结局哪个维度不合适，再换方向。只对局部不满意时保留已认可部分。完成标准是形成可展开的故事方向，并能说明它对应了哪些用户偏好；代理自行推荐不等于用户已选定。

### 用大纲与试写验证

方向收敛后，先展开有起承转合、关键选择和明确结局的故事大纲，再试写一场代表性的戏，如第一次冲突、关键对话或核心喜剧场面。多集先给系列主线与分集走向，并用代表场验证表达，不一次展开全季完整剧本。

试写采用第 1 节的角色扮演与逐场写作要求，完整呈现所选场景的情景描述、动作和角色对白；它是成稿质量的样章，不因“试写”而降为梗概或几句示意台词。

大纲验证“是否喜欢故事怎么发展”，试写验证“是否喜欢人物说话方式、节奏和情绪”。反馈只涉及对白或表演时调整表达；涉及动机、冲突或结局时回大纲修订。概念被选中不代表完整剧本已被认可。

完成标准是方向与表达已有足够反馈，或用户已授权按当前判断直接写作，然后进入第 1 节。用户只要提案、大纲或试写时，到所需产出即止；这一阶段不生成正式素材或提交 GPU。已有项目的偏好和采用方向归入其既有设定／剧本文档，不另建平行记录。

## 1．完整剧本先成立

先明确人物目标、关系、事件推进和本集结束时的变化。写出动作与对白的完整因果链，再按实际节奏估时；不把梗概当剧本，不机械分成等长场次。

**试写与完整剧本都以写好每一场戏为优先，不以节省 tokens 为目标。** 给每个情景描述、角色动作和每句对白足够的创作与修订投入，不用“二人争执一番”“她解释了事情经过”“同上”“略”等概述替代应当展开的戏。篇幅由戏的需要决定；充分写作不等于增加无信息对白、重复描述或为凑时长加戏。受单次输出长度限制时，按场次或集分批完整写入项目剧本文档并继续，不把后半段压成提纲，也不把未完成稿称为完整剧本。

以**角色扮演**方式逐场写作与读戏：进入每个角色当下的处境，依据其已知信息、欲望、顾虑、关系与说话习惯行动和回应。先明确本场角色想从对方那里得到什么，再让每句对白承接对方刚说的话、刚做的动作或眼前发生的变化。角色可以回避、试探、误解或言不由衷，但须符合其动机；不让所有人共享作者的全知视角或只为讲解剧情而说话。

- **情景描述**：写清时间地点、必要环境与氛围、人物初始状态和场内变化；把情绪落实到可见动作、表情、停顿或声音，使读者能想象、演员能表演。细节服务于人物、因果或气氛，不堆砌无关修饰，也不在此提前替代正式分镜。
- **角色对白**：逐句写出实际台词，区分角色的词汇、句式、节奏与表达习惯；让潜台词、沉默、打断和动作参与交流，避免每个人都直白解释自己的感受。对白既回应当下，也推动关系或事件发生变化。
- **逐场复核**：完成一场后，分别代入每个角色读戏，检查“以此人的身份和已知信息，此刻会这样说、这样做吗”；再从观众角度检查情境是否清楚、情绪转折是否有依据、对话是否自然。**专项复核年代时间线、行业与生活常识，逐句拆解潜台词与金句的主谓逻辑，剔除违背常理的伪深刻表达。** 发现敷衍概述、人物同声同气、常识硬伤或反应跳跃时，修订该场后再推进。交付具体剧本文本，不用角色分析或自评代替成稿。

检查每个承接动词的前提：谁拿到了物件、为何递给别人、为何离开或返回、谁知道了什么。付款后找零、借出后归还、碰触后反应，都需要观众能理解的前置事件；不要从一句“追上”“塞回”“又来了”倒推出镜头里从未发生的剧情。非关键过程可以省略，但省略后的结果须可理解。

逐句读戏，给行动、反应和换气留时间。集时长按“容量区间”处理，不按固定目标反推节拍：先写完整因果，再量 floor／预计／上限；超长先减少非必要停顿或调整拍法；缺桥另行补足，不能把补桥当缩短手段，不删因果节拍，不擅自删台词或机械加速。剧本、分镜、实际成片三者时长不必相等，做法见[时长与流畅度](duration-and-flow.md)。面向长台词拆段时保留语义、情绪和动作阶段。

多集额外检查：每集起止状态、人物已知信息、服装与道具变化、伏笔何时可见。公共母版在共享位置维护，每集使用的版本复制／锁定，避免后续改母版改变旧集输入。

多段制作先按[生成片段规划与落地](segment-planning.md)建立镜头到请求的映射，再准备素材。全片提示词可先写为完整草稿，尚未生成的引用与边界状态明确标记依赖。

## 2．分镜先建立空间与调度

先画简明场景平面／关系草图：入口、通道、功能区、家具、关键物件与光源。空间名称按实际场景定义，不把某种店铺、房间或柜台结构写成全局规则。剧本定稿后只提前固定人物、标志性场景特征与关键道具；房间的固定空间关系用四图共同约束；人物与道具的当前状态、光位用动态追踪——单集从第一条通过验收的片段开始抽帧，持续更新本集状态账本，做法见[一致性资产](consistency-assets.md)。

场景空间基准按固定顺序制作：正面图 → 参考正面图生成反向平视回望图 → 参考前两张生成45°俯视斜角全景图 → 参考前三张生成90°垂直正俯视完整平面图。步骤间先检查，实际输入逐步累积，不并行生成本组后续图；四图交叉核对同一布局。每条涉及该场景的生成任务（含反打、续接、补拍）四图一起绑定，不能挑单图；新任务声明场景关联，不各镜自由生成房间。

每个镜头明确：

| 项目 | 要回答的问题 |
| --- | --- |
| 空间与机位 | 相机在哪、朝哪；本镜相对于哪条人物关系轴线？ |
| 人物关系 | 谁在何处、身体朝哪、眼睛看谁；谁在画外，是否露肩或手？ |
| 动作因果 | 哪个动作先发生，谁看到／听到后才反应？ |
| 道具与接触 | 谁用哪只手拿什么、接触点在哪里、交接何时完成？ |
| 可读性 | 所选景别能否看见决定剧情的小动作或表情？ |
| 时间与声音 | 自然对白与动作能否容纳；是否跨切点继续声音？ |
| 出入点 | 上镜结束和本镜开始能否解释，哪里需要移动／时间省略？ |
| 依赖 | 同镜续接、反打、插入还是换场；需要哪个实际版本／切点？ |
| 切点状态 | 切点两侧谁在画内、各人动作阶段、道具位置；下一镜站位与动作是否已有可理解的依据？ |
| 状态变化 | 站起／坐下、进出画、拿起／放下，是在本镜完成、匹配动作切点、补桥，还是有依据地省略？ |

“保持同一轴线”“自然反应”“面向对手”都不能替代具体位置。换机位后重新换算屏幕左右；物理位置固定，屏幕左右可变。不要为了正面展示脸，让人物转向错误的说话对象。

机位规划：按信息增量、表演负载和节奏选择连续长镜或切镜，不设固定机位数；轻微重构图可用运镜。切镜保持可理解的关系轴线，越轴须交代空间。相邻两段同机位、同段对话且合起来不超上限时，若表演与信息负载合适，可合并成一条并在提示词里按顺序排台词与动作；旧的两段保留为历史版本。

场景转入转出可用动作、视线、环境声、时间提示或建立镜头完成；不用每场都多加空镜。先前缺少离开过程，后面就不能无交代地“从外面回来”。

## 3．复杂行为先做可读设计

递接拆成可观察状态：物件在甲手中→乙接触／承托→甲松开→物件归乙。选择能看见交接的位置与景别，避免小物被身体遮挡。动作过多时分镜、延时或简化表演，不要求人物同时移动、换手、复杂操作和长篇说话。

对笑点、误会或揭晓，观众必须先看清其信息来源。仅在台词中提到“这个”并不能补救画面中看不清的指代。背景道具与关键道具分别处理，按当镜可见状态引用，避免提前泄露后续揭晓物。

## 4．按镜头固定身份、构图、声音

身份图负责人物外观，场景四图负责环境，构图参考负责当前机位与人物关系；三者用途不同。需要画外人物露肩或手时，绑定其身份和服装，不让模型自由添加泛称的对手。同场按生成片段依赖推进：第一段结合已验收四图、静态锚与起始状态准备素材；生成并验收后抽帧记入账本，依赖它的下一段据此准备素材。一段内部可有多个镜头，不要求每次段内切镜先停下来生成一张关键帧。整场关键帧不批量预生成。关键帧不合格先重出，不带病进生成。

按需要固定服装、身高比例、关键道具状态和声线。新建声线可用已授权的首批生成片段提取，但应先听审；来源、采用区间和版本留档。任何单一参考都不能保证跨镜完全一致。

## 5．从分镜转换为提示词与任务

逐镜核对说话对象、动作先后、场面位置、持物和可见人数，再检查 H3 的主体／图片／音频引用与真实输入。文本中不得一处要求角色看左侧对手，另一处却让主要视线回到右侧另一人，除非确实设计了可见的转向过程。

同镜头续接下游先保持草稿，待上游最终选片和实际末帧准备好后才就绪。其他镜头不自动设尾帧依赖，也不因标注“反打”而免除关系检查。

## 6．生成、粗剪、内容验收

按[执行适配](comfyui-h3.md)直接二采并逐条保存。用代表性对手戏、关键接触动作和真实续接检验方案；具体需要哪些小样由风险决定，已授权整批无需重复审批。

每个场景尽早粗剪检查，使用[连续性与验收](continuity-and-review.md)区分计划、实际观察、技术成功和内容通过。失败时先判断脚本／分镜、提示词、输入绑定、生成、剪辑还是验收问题，再修对应环节；不能只换 seed 批量碰运气。

交付前完整观看和听审，复核单集叙事及跨集起止状态。镜头版本和剪辑区间写进选片清单，不覆盖源文件换片。
