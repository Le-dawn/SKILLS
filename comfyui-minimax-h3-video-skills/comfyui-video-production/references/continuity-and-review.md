# 连续性、验收与诊断

用于分镜审查、提示词语义核对、选片、同镜续接、相邻镜检查和成片问题复核。术语（镜头、片段、版本、同一镜头的判定）以[术语表](glossary.md)为准。验收强度按内容需求选择；人物对手戏要检查视线，纯产品展示则检查产品状态和演示因果，不套无关项目。

## 先核对意图是否正确传递

用同一镜头的“脚本→分镜→正式提示词→实际提交图→源片→成片”建立可追溯关系。

- 对象与目的：谁对谁说话、看谁、触碰什么；画外角色需要露手／肩时是否绑定身份与服装。
- 动作顺序：触发事件、观察／听到、反应、结果；不能把“先示意再执行”改成开场已在执行。
- 关键状态：人数、位置、持物、数量、开合／损坏状态、可见信息是否保持；不要提前描述未揭晓物。
- 时间与构图：动作与完整对白能否自然完成，景别能否看见关键细节；不要只写“自然、连贯”。

优先消除提示词内部冲突和计划遗漏，再让模型执行。若工作流或文本已提交，以实际快照为证据；当前文件可能是后改版本，不能默认相同。

## 跨生成片段的状态与声音

对照[片段计划](segment-planning.md)分别检查段内切镜和段间接缝，二者不必重合。上游的实际出口与下游入口核对持物手、开合、朝向、视线、动作阶段及未结束声音；必要情节与固定布局偏差须修复，不能只改账本来接受。局部参考标签与说话人编号可变，全局人物／声线身份不可漂移。

跨段对白优先完整句边界；确需跨段时核验实际连续音源或剪辑方案。`<scenetrans>` 只表达单份提示词内跨切镜对白，不会自动接通两次生成。整片音乐与环境声需记录持续／结束方式，不让每段自动重新起奏、淡出或重复台词。

## 同一镜头的真正续接

1. 等上游完整二采完成并下载，选定实际版本及剪辑区间。区间使用 0 起始、左闭右开 `[in_frame, out_frame_exclusive)`；尾帧为 `out_frame_exclusive - 1`，不是默认源片最后一帧。
2. 检查尾部约 0.5–1 秒，记录运动方向、速度、动作阶段、视线和接触点。单张静帧不能还原这些信息。
3. 保存原尺寸尾帧或经过明确统一变换的尾帧，记录源片哈希、实际帧号、提取图哈希、裁切／缩放。上下游使用同一画幅和坐标体系，不把后期裁切与原始全幅混用。
4. 多参考路径中，把尾帧加入真实图片数组并设正确的 1 起始 `anchor_image_index`，提示词明确其首帧作用和如何继续动作。核查有效图的 Guide 连接；不能把普通参考描述成真实首帧绑定。
5. 下游需要足够源帧供剪辑。若选择跳过重复的第 0 帧，预留这一帧的时长并核对实际输出；是否跳帧由实际首尾动作决定，不机械删帧。记录下游采用区间。
6. 按实际剪辑拼接，连播切点前后各约 1 秒；复杂动作扩展到整个动作。检查位置、姿态、手部／持物、光照、景别、机位、方向和速度，以及声音是否重复、截断或突变。
7. 上游版本、切点或变换变化，重新提取尾帧并检查所有受影响下游；不默认旧锚图继续有效。需要重做时新版本，不覆盖原任务。

同 seed 不保证接缝不变。首尾状态正确也不能证明中间没有新生物件、穿模或不合理动作。未解决的连续性不能靠叠化隐藏；改为有意切镜会改变镜头设计，应遵守用户已有创作约束。

## 有意切镜与反打

不要求像素首尾相同，但必须检查人物相对位置、视线落点、道具归属、动作阶段、出入方向与时间省略。镜头切换后服务区／顾客区、室内／室外等物理位置不能无交代互换。

切点状态检查：每条切点单独过六项，全过才采用——

| 项 | 不合格表现 |
| --- | --- |
| 在场人物 | 人物离场或物理位置变化无依据；正常切近景使其出画不算离场 |
| 动作阶段 | 关键动作阶段无依据跳跃，且不能由匹配切点或明确省略解释 |
| 道具 | 凳子、盒子、伞等的位置、朝向或归属变了 |
| 机位关系 | 机位、越轴或景别变化使空间关系无法理解，且无设计依据 |
| 光 | 同一场的光比、色温突变 |
| 声音 | 说话人跨切点断裂或重复 |

切点必须连播前后各约 1 秒，不能只看静帧。若观众无法理解下一镜站位与动作，补足空间或动作依据；不要求所有目的位置在出口镜画内可见。

只见一角陌生衣服时，先记录身份／服装异常，不臆断是谁。单人近景也可成立：根据分镜和叙事判断，不一律要求对手同时入画。反打需要新机位关系构图，不把上一镜尾帧直接当新机位首帧。

切点对比先区分机位关系：固定机位续接可用原尺寸叠看定位异常，但不以像素完全相同判定；运动镜头须考虑预期运动。换机位时背景投影、遮挡和屏幕位置本就会变化，应结合空间基准检查固定物的物理关系及动态账本，不做“只有人物能变”的差分判定。若确认固定物无依据重建，回到分镜或关键帧来源修复，调色不能修复几何。

## 内容检查与证据范围

| 检查 | 应观察的结果 | 不能替代它的证据 |
| --- | --- | --- |
| 视觉可读性 | 正常观看能理解关键动作和物件指代 | 放大静帧才勉强看见、提示词写过 |
| 空间与对象 | 人物确实看向／说给正确对象，出入关系成立 | 角色脸像、背景相似 |
| 接触与递接 | 接触点、承托、松手和最终归属清楚 | 只是手伸向身体附近 |
| 动作因果 | 触发和反应顺序正确，省略可理解 | 只比较开头和结尾 |
| 对白与声音 | 原声台词、说话人、语气、口型和跨镜声音可接受 | 剧本一致的硬字幕、ASR 覆盖率 |
| 剪辑与文件 | 采用版本、实际帧数、字幕时间、音量与画幅正确 | 执行完成、解码成功 |

抽帧发现疑点后增加局部密度和前后文；接触／交接还须动态检查。ASR 只定位疑似漏词、改词或错说话人；同音误识不能直接判口误，也不能把所有差异直接说成识别错误。合成字幕独立于生成口播，不是声音正确的证据。

工具无法真实播放、听到或查看某项时，写明做了什么、未做什么。用户反馈与 AI 观察分开；不得把抽帧复核称为完整连播听审。

## 选片、修复与记录

在项目既有选片清单或制作记录中记事实，不为普通制作问题新建架构 Note。至少保留：逻辑镜头、采用任务版本、源片／哈希、入出帧、实际时间码、上游依赖、已做检查、未完成检查、异常和处置。每个片段版本独立 ID、独立输出目录与回执，旧版本不覆盖；采用关系只写在选片清单里，另维护一张片段版本表（镜／版本／seed／帧数／状态／弃用原因），避免后期误读“最新文件”。

每项验收分开写“设计要求”“实际观察”“证据与检查方式”“结论”。例如“拟要求看向入口”不是“实拍已看向入口”；“执行器 completed”不是“内容通过”。已知问题允许保留时说明影响及用户取舍，不能替用户认可。

以下通常阻断内容通过：关键人物对错人说话、物理位置无交代互换、关键物件／款项交接未完成、关键因果缺失、无法辨认的新增人物、原声严重漏词或误导性演示。轻微景别偏差、表演差异是否可留，按叙事影响判断，不一律重跑。

定位责任时按证据区分：

1. 脚本／分镜没设计或设计矛盾：先补因果、调度或可读镜头。
2. 提示词遗漏、改错、内部冲突：修转换，不靠增加采样次数解决。
3. 工作流输入绑定与计划不同：查实际图、标签顺序、素材哈希、Guide 接线和选中版本。
4. 输入明确且已传入，画面仍偏离：记录为生成结果偏离；无实验不能进一步断言是某采样节点、模型或 LoRA 的根因。
5. 源片可用、成片有误：查选片、剪辑切点、缩放裁切、配音与字幕。
6. 缺陷已存在仍获通过或 QA 误记：修正验收记录，保留历史来源，不悄悄将预期写成事实。

先修局部最有影响的问题，再检查其依赖；不默认全片重做。新生成使用新版本，并按用户授权范围执行。

## 成片交付

按选片清单和帧区间组装，尽早粗剪。精确字幕、图解、片内文字和音量用可复现后期；输出规格与画幅根据当前任务，不默认 1080×1920、固定响度或三分钟。

交付前完整观看和原声听审，专项检查相邻镜；完成实际片长、帧率、音轨、字幕、完整解码检查。输出进入候选目录，内容通过后才作为正式交付；未经用户批准的 AI 检查结果不要称为用户验收。

说明实际完成范围与剩余问题，并区分静态参考、声音规范、实际音频、生成源片和后期成片。后期放大不称模型原生高清；技能和流程改进不代表既有影片问题自动修复。
